# README 中文化设计

## 目标

将项目唯一的根目录 `README.md` 全部改写为自然、准确的中文说明，使中文用户可以直接完成依赖安装、编译、建图、地图导出、定位、RViz 初始位姿设置和轨迹评估。

## 翻译边界

- 翻译全部标题、段落、列表说明、代码注释和操作提示。
- 保留项目名、数据集名以及 ROS、PCL、Eigen、GTSAM、BTC、ATE、RPE 等技术名称。
- 保持 shell 命令、文件路径、YAML 键、ROS 参数和话题名原样。
- 保留现有链接和图片引用。
- 修正原说明中明显的拼写及命令错误，例如重复的 `roslaunch`，但不修改程序代码或运行行为。

## 文档结构

沿用当前章节顺序：项目简介、相关资源、依赖、编译、各数据集运行方式、地图导出与定位、评估工具、RViz 点云插件。新增的地图定位说明保持与当前代码和配置一致。

## 验证

- 检查 Markdown 代码块成对闭合。
- 检查所有原有 URL 和关键命令仍然存在。
- 搜索残留英文说明；允许专有名词、命令和代码标识继续使用英文。
- 运行 `git diff --check`，确保没有空白格式问题。
